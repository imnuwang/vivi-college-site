# 過去、現在、未來牌陣 QA 紀錄

## 驗證範圍

本紀錄針對 `/tarot-daily` 的新三張牌陣進行實際互動驗證。目標是確認使用者可以切換「單張抽牌」與「過去、現在、未來」，且三張模式會依序揭示三張不同的經典 Rider–Waite–Smith 牌面，並取得非預言式的 AI 綜合自我覺察內容。

| 項目 | 實測結果 |
| --- | --- |
| 模式切換 | 成功切換至「過去、現在、未來」；單張模式入口仍保留。 |
| 三張牌揭示 | 成功依序出現「過去 → 現在 → 未來」的牌面；本次為命運之輪、愚者、魔術師，三張皆不同。 |
| 牌面與牌背 | 揭示前使用美心學苑深墨綠／霧金月亮星星牌背；揭示後正確呈現對應經典牌面、牌名與關鍵字。 |
| AI 綜合解讀 | 成功顯示各位置解讀、「三張牌一起說的事」、下一步與書寫題。 |
| 非預言界線 | 未來位置明示為「若沿著覺察前進，正在形成的下一步方向」；AI 解讀包含「這不是預言」及自我覺察、非專業意見聲明。 |
| 手機版 | 以 375 × 812 全頁截圖檢查，單張模式首屏、模式選擇、牌背、輔助說明與頁尾皆維持可讀的單欄版面；三張牌陣的手機 CSS 已設定為單欄堆疊。 |

> 本工具將牌面視為書寫與自我覺察提示，不提供命運預測，不作重大決策或專業意見的替代。
